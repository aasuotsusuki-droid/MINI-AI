How it works

From your voice to an action in a few steps.

1️⃣

Listen

The microphone captures your voice.

2️⃣

Understand

Speech is converted to text and matched to a command.

3️⃣

Act

The assistant runs the task on your PC.

4️⃣

Reply

It speaks the result back to you.

Run it on your PC

Needs Python 3 and a working microphone.

git clone https://github.com/aasuotsusuki-droid/MINI-AI.git
cd MINI-AI
pip install -r requirements.txt
python main.py

Because the assistant uses your microphone and opens Windows apps, it runs locally on your computer. This page is a showcase of the project.
